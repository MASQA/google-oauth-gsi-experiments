# 📋 Инструкция по использованию системы

## 🚀 Быстрый старт

### 1. Запуск сервера

```bash
cd examples/next-js
npm install
npm run dev
```

Откройте http://localhost:3000

### 2. Вход в систему

1. Нажмите "Sign in with Google"
2. Выберите аккаунт Google
3. Вы будете перенаправлены на Dashboard

### 3. Тестирование системы

#### Вариант 1: Dashboard with Privileges (Рекомендуемый)
- Перейдите по кнопке "Privileges Demo" или откройте `/dashboard-privileges`
- Используйте кнопку "Use Service (1 call)"
- Счетчик будет уменьшаться
- Данные сохраняются в файл

#### Вариант 2: Dashboard Secure
- Откройте `/dashboard-secure`
- Используйте кнопку "Use Secure Service (1 call)"
- Счетчик будет уменьшаться
- Данные сохраняются в файл

## 📁 Где хранятся данные

### Файл с данными:
```
examples/next-js/data/usage-storage.json
```

### Пример содержимого:
```json
{
  "google_user_id_123": {
    "userId": "google_user_id_123",
    "email": "user@example.com",
    "serviceCalls": 9,
    "subscriptionTier": "free",
    "createdAt": "2025-12-30T07:00:00.000Z",
    "lastCallAt": "2025-12-30T07:05:00.000Z",
    "version": 2
  }
}
```

## 🔧 Что было исправлено

### Проблема:
- При logout/перезагрузке счетчик сбрасывался
- Данные хранились только в памяти (Map)

### Решение:
- ✅ Реализовано постоянное хранение в файл
- ✅ Данные сохраняются после logout
- ✅ Данные сохраняются после перезагрузки сервера
- ✅ Добавлены кнопки оплаты при исчерпании лимита

## 🎯 Ключевые изменения

### 1. Endpoint изменен:
```typescript
// Было:
fetch('/api/service/usage', { method: 'POST' })

// Стало:
fetch('/api/service/persistent-usage', { method: 'POST' })
```

### 2. Добавлены кнопки при лимите:
- 💳 **Upgrade Plan** → Переход на страницу оплаты
- 💬 **Contact Developer** → Ссылка на Telegram

### 3. Страница оплаты:
- Доступна по адресу `/payment`
- Выбор плана: Premium ($9.99) или Enterprise ($29.99)
- Интеграция с платежными системами (демо)

## 🧪 Тестирование

### Тест 1: Сохранение данных
1. Войдите в систему
2. Используйте сервис 3 раза
3. Нажмите Logout
4. Войдите снова
5. **Результат:** Должно остаться 7 вызовов

### Тест 2: Перезагрузка сервера
1. Используйте сервис несколько раз
2. Остановите сервер (Ctrl+C)
3. Запустите снова (`npm run dev`)
4. Войдите в систему
5. **Результат:** Счетчик должен сохраниться

### Тест 3: Исчерпание лимита
1. Используйте сервис 10 раз
2. **Результат:** Появится сообщение "Limit Exceeded!"
3. Появятся кнопки "Upgrade Plan" и "Contact Developer"

## 🔐 Безопасность

### Защита от подделки:
- ✅ Серверная проверка токена на каждом запросе
- ✅ Привилегии хранятся на сервере (не в cookie)
- ✅ Клиентские данные игнорируются
- ✅ HttpOnly cookie защищает от XSS

### Как проверить безопасность:
1. Попробуйте подделать cookie `g_state`
2. Попробуйте изменить JavaScript
3. Попробуйте отправить запрос с 0 вызовов
4. **Результат:** Все попытки будут отклонены сервером

## 🚨 Устранение проблем

### Проблема: Файл usage-storage.json пустой
**Решение:** Используйте сервис хотя бы 1 раз, файл создастся автоматически

### Проблема: Данные все равно сбрасываются
**Решение:** Убедитесь, что используете endpoint `/api/service/persistent-usage`

### Проблема: Не видно кнопок оплаты
**Решение:** Дождитесь исчерпания лимита (10 вызовов)
